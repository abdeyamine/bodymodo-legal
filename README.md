# Bodymodo - Legal

Public legal documents for the [Bodymodo](https://play.google.com/store) Android app.

- **[Privacy Policy](https://abdeyamine.github.io/bodymodo-legal/privacy-policy.html)**
- **[Delete Account and Data](https://abdeyamine.github.io/bodymodo-legal/delete-account.html)**

Hosted via GitHub Pages. To update:

1. Edit the relevant HTML document
2. Update the "Last updated" date in the document
3. Commit and push to `main`
4. Changes go live in ~30 seconds
